2026-09-09, Node.js 22.21.1, macOS / Google Chrome에서 확인했습니다.

- `npm run build`: TypeScript 및 Vite 프로덕션 빌드 통과.
- `npm test`: 서버·MCP 통합 테스트 **55개 통과**.
- Playwright 브라우저 시나리오 **7개 통과**. AI 설정 저장·응답 생성·사용량 반영 시나리오를 포함합니다.
- 브라우저 runtime JavaScript 오류 없음.
- 1440px 데스크톱과 390px 모바일에서 가로 넘침 없음.
- 실제 ZIP 업로드 → 리비전 → 별도 호스트 미리보기 → 게시 → 배포 앱 클릭 동작 확인.
- 데이터 문서 생성·수정·삭제·복구, 관리자 지정, 설정의 재로딩 후 영속성 확인.
- MCP stdio 도구 목록, 실제 예제 빌드·배포, 해시 검증 pull, 기존 목적지 덮어쓰기 거절 확인.

자동 테스트 DB와 실행 파일은 임시 디렉토리에 격리하며 테스트 종료 후 삭제합니다. 사용자의 `.data/`를 테스트 시나리오로 변경하지 않습니다.

회사 Keycloak, 실제 PostgreSQL/MariaDB, STaRT, Trace LLM, nginx, 감사 스풀, 백업·복구·부하 시험은 수행하지 않았습니다. 이는 로컬 개발 검증이며 전사 출시 게이트 통과를 의미하지 않습니다.

## Ollama 연결 검증

- 자동 Ollama 테스트 15개: 로컬 모델 검색, 권한·모델 제한, 본문 미저장, 예산 동시 예약·정산, 분당·동시성 제한, 오류 정규화, 오프라인 차단, 응답 중 권한 회수, 활성 리비전 검사, 민감 API 조합 거절, 타임아웃·취소 전달. 자동 테스트는 결정적인 mock Ollama를 사용합니다.
- 실제 설치된 Ollama 0.33.2에서 qwen3.5:latest / gemma4:latest 모델 검색을 확인했습니다. 새 모델을 다운로드하지 않았습니다.
- 실제 관리 화면의 하반기 평가 가이드 → AI에서 qwen3.5 모델을 설정하고 환영 인사 생성 성공을 확인했습니다. 입력 29 / 출력 92 토큰이 화면과 사용량에 반영되었습니다. 이 수동 확인을 위해 해당 예시 프로젝트의 AI 설정을 켜 두었습니다.
- 실제 Ollama 대화 응답은 플랫폼 서버를 통과합니다. 자동 테스트의 예시 응답을 실제 모델 결과로 표시하지 않습니다.
